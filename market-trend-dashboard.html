ตั้งค่าก่อนเริ่มใช้งาน

Dashboard นี้ต้องเชื่อมต่อ 2 อย่าง: ฐานข้อมูล Supabase (เก็บ watchlist + cache ราคา) และ API ราคาตลาดจาก Twelve Data

  1. Supabase: สมัครบัญชีฟรีที่ supabase.com → สร้างโปรเจกต์ใหม่ (แนะนำแยกจากโปรเจกต์สต๊อกสินค้าเดิม) → ไปที่ SQL Editor แล้วรันสคริปต์ตาม schema.sql ที่แนบมาด้วย
  2. Twelve Data: สมัครบัญชีฟรีที่ twelvedata.com (ฟรี 800 requests/วัน ไม่ต้องผูกบัตร) → คัดลอก API Key จากหน้า Dashboard
  3. แก้ไขค่าคงที่ 3 บรรทัดด้านล่างในไฟล์นี้ (ใกล้ท้ายไฟล์):
const SUPABASE_URL = "https://YOUR-PROJECT.supabase.co";
const SUPABASE_ANON_KEY = "YOUR-ANON-KEY";
const TWELVEDATA_API_KEY = "YOUR-TWELVEDATA-KEY";

บันทึกไฟล์แล้วเปิดใหม่ (หรืออัปโหลดขึ้น GitHub Pages เหมือนแดชบอร์ดสต๊อกสินค้า) — ระบบจะตรวจสอบอัตโนมัติและซ่อนหน้านี้เมื่อกรอกครบ

ส่วนเสริม (ไม่บังคับ): CME Futures + COT Report

COT Report (Commitment of Traders): ใช้งานได้ทันที ไม่ต้องตั้งค่าเพิ่ม — ดึงข้อมูลฟรีจาก CFTC โดยตรง จะขึ้นให้อัตโนมัติเมื่อสัญลักษณ์ที่เลือกมีข้อมูล COT ตรงกัน (ทองคำ, เงิน, น้ำมันดิบ WTI, ก๊าซธรรมชาติ, คู่เงินหลัก, S&P 500 E-mini, Nasdaq E-mini) — รันเพิ่มตาราง cot_cache ตาม schema-additions.sql ที่แนบมาก่อน

ราคา Futures (เช่น Gold GC, Euro FX 6E, Crude Oil CL): Twelve Data ไม่มีข้อมูล futures ของ CME ให้ ต้องตั้งค่า Supabase Edge Function เป็นตัวกลางไปดึงจาก Yahoo Finance แทน (ไม่บังคับ — ถ้าข้ามขั้นตอนนี้ ส่วนอื่นของแดชบอร์ดยังใช้งานได้ปกติ เพียงแต่จะเพิ่มสัญลักษณ์ futures ไม่ได้):

  1. ติดตั้ง Supabase CLI (npm install -g supabase) แล้ว login + link กับโปรเจกต์เดิม (supabase login, supabase link --project-ref YOUR-PROJECT-REF)
  2. สร้างโฟลเดอร์ฟังก์ชัน แล้ววางไฟล์ futures-proxy/index.ts ที่แนบมาไว้ที่ supabase/functions/futures-proxy/index.ts
  3. Deploy: supabase functions deploy futures-proxy
  4. คัดลอก URL ฟังก์ชันที่ได้ (รูปแบบ https://YOUR-PROJECT-REF.supabase.co/functions/v1/futures-proxy) มาใส่ในค่าคงที่ FUTURES_PROXY_URL ใกล้ท้ายไฟล์นี้

เมื่อตั้งค่าแล้ว เพิ่มสัญลักษณ์ futures ในรายการเฝ้าดูได้โดยใช้รหัสสัญญา เช่น GC (ทองคำ), SI (เงิน), CL (น้ำมันดิบ WTI), NG (ก๊าซธรรมชาติ), 6E (Euro FX), 6B (GBP), 6J (JPY), 6A (AUD), 6C (CAD), 6S (CHF), 6N (NZD), ES/MES (S&P 500), NQ/MNQ (Nasdaq) — ระบบจะรู้จักอัตโนมัติว่าเป็น futures และไปดึงผ่าน Edge Function แทน Twelve Data

หมายเหตุ: ราคา futures มาจาก Yahoo Finance (แหล่งข้อมูลสาธารณะที่ไม่เป็นทางการ ดีเลย์ ไม่รับประกัน uptime) ผ่าน Edge Function ที่คุณเป็นคนดูแลเอง — ไม่ใช่ real-time feed จาก CME โดยตรง ช่วงเวลา 4 ชั่วโมงคำนวณจากการรวมแท่ง 1 ชั่วโมงเอง (ไม่ใช่แท่ง 4h จริงจากตลาด) ส่วน Volume/Open Interest ของ CME ไม่มีแหล่งข้อมูลฟรีที่ดึงตรงได้ (ต้องใช้ CME DataMine แบบเสียเงิน) จึงยังไม่รวมไว้ในเวอร์ชันนี้

แนวโน้มตลาด

รูปแบบสัญลักษณ์ตาม Twelve Data — คู่เงิน/ทองคำใช้ "/" เช่น XAU/USD, หุ้นพิมพ์ตัวย่อเฉย ๆ เช่น AAPL หรือใช้รหัส Futures ของ CME เช่น GC, SI, CL, NG, 6E, 6B, 6J, 6A, 6C, ES, NQ (ต้องตั้งค่า Futures Proxy ก่อน — ดูหน้าตั้งค่า)
