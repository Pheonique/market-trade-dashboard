ตั้งค่าก่อนเริ่มใช้งาน

Dashboard นี้ต้องเชื่อมต่อ 2 อย่าง: ฐานข้อมูล Supabase (เก็บ watchlist + cache ราคา) และ API ราคาตลาดจาก Twelve Data

  1. Supabase: สมัครบัญชีฟรีที่ supabase.com → สร้างโปรเจกต์ใหม่ (แนะนำแยกจากโปรเจกต์สต๊อกสินค้าเดิม) → ไปที่ SQL Editor แล้วรันสคริปต์ตาม schema.sql ที่แนบมาด้วย
  2. Twelve Data: สมัครบัญชีฟรีที่ twelvedata.com (ฟรี 800 requests/วัน ไม่ต้องผูกบัตร) → คัดลอก API Key จากหน้า Dashboard
  3. แก้ไขค่าคงที่ 3 บรรทัดด้านล่างในไฟล์นี้ (ใกล้ท้ายไฟล์):
const SUPABASE_URL = "https://YOUR-PROJECT.supabase.co";
const SUPABASE_ANON_KEY = "YOUR-ANON-KEY";
const TWELVEDATA_API_KEY = "YOUR-TWELVEDATA-KEY";

บันทึกไฟล์แล้วเปิดใหม่ (หรืออัปโหลดขึ้น GitHub Pages เหมือนแดชบอร์ดสต๊อกสินค้า) — ระบบจะตรวจสอบอัตโนมัติและซ่อนหน้านี้เมื่อกรอกครบ
